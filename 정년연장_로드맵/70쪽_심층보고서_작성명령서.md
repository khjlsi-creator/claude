작성일 2026.10.31. / 용도: 새 Claude 대화창(또는 Claude Code)에 복사해 단계별로 붙여 넣는 지시문 모음

## 0. 먼저 이해할 것 (쉬운 설명)

**왜 한 번에 "70쪽 써줘"가 안 되는가**
- 비유: 집 한 채를 설계도 없이 한 번에 짓는 것과 같음. 방(장)별로 설계 → 시공 → 점검을 거쳐야 튼튼함
- AI도 한 번에 길게 쓰면 뒤로 갈수록 내용이 흐려지고, 앞에서 쓴 숫자와 뒤의 숫자가 어긋나며, 없는 근거를 지어내기 쉬움
- 그래서 **① 자료 준비 → ② 설계도(쪽수 배분) → ③ 장별 작성 → ④ 검수 → ⑤ 합본** 순서로 진행

**70쪽 분량 배분안 (A4, 본문 10pt, 표·도식 포함)**

| 구분 | 쪽수 | 내용 |
|---|---|---|
| 표지·요약·목차 | 4 | 한 장 요약 + 경영진 판단사항 |
| Ⅰ. 추진배경 및 목적 | 6 | 정책동향, 사실확인, 필요성, 목적·범위 |
| Ⅱ. 대내외 환경분석 | 14 | (1) 대외 7쪽, (2) 대내 7쪽 |
| Ⅲ. 크로스 SWOT 분석 | 8 | 12개 요인, 조합전략, 시사점 |
| Ⅳ. 전략체계도 | 6 | 미션·비전·목표·과제 연계, 선후관계 |
| Ⅴ. 추진과제 및 세부추진과제 | 26 | 9대 과제 × 약 3쪽 = 27쪽 내외 + 총괄 |

## 1. 1단계 — 역할·원칙 선언 (대화 맨 처음에 붙여 넣기)

```
너는 한국 공공기관(한국원자력환경공단) 인재경영팀을 돕는 정책 보고서 작성자다.
우리는 "정년연장 대응 미래일터 중장기 로드맵" 심층보고서(A4 약 70쪽)를 만든다.

[배경 사실 — 내가 제공한 확정 사실]
- 임금피크제: 2년, 일반직만 적용, 공무직은 제외
- 임피 기간 보수 80% 지급(연차별 각각), 1일 근로시간 6시간
- 노조: 복수노조. 제2노조는 공무직 중심
- 구성원: 일반직, 공무직
- 2026년: 노사 공동 미래일터 위원회와 실무 TF 구성, 역량강화, 로드맵 수립
- 2029년: 정년연장 도입 목표(조건 충족 시)
- 검토 범위: 직무·인사·보수 전 분야

[작성 원칙]
1. 사실·추정·가정을 반드시 구분해 표시한다. 확인 못 한 것은 "확인 전", 자료 없는 수치는 "미집계"로 쓴다.
2. 존재 여부가 불확실한 법령·조문·통계·기사·논문은 절대 지어내지 않는다.
3. 정년연령·보수율·근로시간 등 세부 수치는 법령 확정과 노사 협의 전이므로 "확정 전"으로 표기하고 단일안으로 고정하지 않는다. 시나리오 A/B처럼 복수안으로 쓴다.
4. 문체는 공공기관 보고서 개조식(□ ○ - 위계, 명사형 종결, 마침표 없음)을 쓴다.
5. 일반인이 읽어도 이해되도록 어려운 용어는 첫 등장에 쉬운 설명이나 예시를 붙인다.
6. 분량을 채우려고 같은 내용을 반복하지 않는다. 쪽수가 모자라면 "분석·사례·표"를 늘리고, 넘치면 줄인다.
7. 모든 수치에는 출처와 기준일을 붙인다("* 근거 : 출처(기준일)").
8. 한 번에 한 장(章)만 쓴다. 내가 "다음 장"이라고 하기 전에는 다음 장을 쓰지 않는다.

이해했으면 "원칙 확인 완료"라고만 답하고, 필요한 자료 목록을 먼저 물어봐라.
```

## 2. 2단계 — 자료 학습·정리 (자료를 올린 뒤)

```
방금 올린 자료를 전부 읽고 아래 3가지 표로 정리해라. 아직 보고서 본문은 쓰지 마라.

(1) 자료 색인표: 자료명 | 종류(내부/외부) | 기준일 | 핵심 내용 3줄 | 신뢰도(원문/2차 정리/기사)
(2) 사실확인 대장: 주장 | 근거 자료 | 확인 상태(확인/미확인/상충) | 비고
    - 특히 "정년연장 65세 도달 시점", "출생연도별 적용"은 자료마다 다르면 상충으로 표시

규칙: 자료에 없는 내용은 추측해서 채우지 말고 (3)에 올려라.
```

## 3. 3단계 — 설계도 작성 (본문 쓰기 전 합의)

```
정리된 자료를 바탕으로 70쪽 설계도를 만들어라. 아직 본문은 쓰지 마라.

[고정 목차 — 변경 금지]
Ⅰ. 추진배경 및 목적
Ⅱ. 대내외 환경분석 : 1. 대외 환경분석 / 2. 대내 환경분석(복수노조·일반직·공무직 구조)
Ⅲ. 크로스 SWOT 분석
Ⅳ. 전략체계도 : 미션 → 비전 → 목표 → 추진과제 → 세부추진과제 → 향후일정
Ⅴ. 추진과제 및 세부추진과제 : 직무 / 인사 / 보수 3개 전략, 9대 과제
Ⅵ. 향후 일정

[설계도에 포함할 것]
- 장·절별 목표 쪽수(합계 70쪽, 표지·요약·목차 4쪽 포함)
- 절마다: 핵심 메시지 1문장 / 들어갈 근거 자료 / 표·도식 필요 여부와 이유 / 필요한 추가 자료
- 장 사이의 논리 연결(앞 장의 결론이 다음 장의 입력이 되는 구조)
- 용어 정의 목록(예: 임금피크제, 정년연장, 계속고용, 직무급, 총인건비)
- 위험 목록: 자료가 없어서 쓰기 어려운 절 TOP 5

완성되면 내가 수정한 뒤 "설계도 확정"이라고 말하겠다. 확정 전에는 본문을 쓰지 마라.
```

## 4. 4단계 — 장별 작성 (장마다 반복해서 붙여 넣기)

```
설계도에 따라 [Ⅱ. 대내외 환경분석 — 1. 대외 환경분석]만 작성해라. (목표 7쪽)

[작성 방식]
- 구조: □ 결론 → ○ 근거 → - 방법·조건 순서
- 각 소절 끝에 "시사점"을 ⇒ 로 한 줄 쓴다
- 표는 비교·일정·분류처럼 표가 꼭 필요한 곳에만 쓰고, 표 뒤에는 한 줄 판단을 붙인다
- 모든 수치에 "* 근거 : 출처(기준일)"를 붙인다
- 일반인용 쉬운 설명: 어려운 개념은 "예를 들어 ~와 같음" 형태로 한 줄 예시를 붙인다
- 확인하지 못한 내용은 "확인 전"으로 표시한다

[쓰기 전에]
이 장에서 사용할 근거 자료와 부족한 자료를 먼저 알려줘라. 부족하면 쓰지 말고 요청해라.

[쓴 뒤에]
(a) 실제 분량(쪽수 추정), (b) 새로 정의한 수치·용어, (c) 확인 전 항목, (d) 앞 장과 어긋나는 부분을 보고해라.
```

장별로 바꿀 부분만 아래처럼 교체

| 순서 | 교체할 문구 | 이 장의 핵심 요구 |
|---|---|---|
| 1 | Ⅰ. 추진배경 및 목적 (6쪽) | 정책동향과 "출생연도별 적용 시나리오 비교표", 사실확인 결과, 목적·범위 |
| 2 | Ⅱ-1. 대외 환경분석 (7쪽) | 법·정책, 노사환경, 청년고용, 연금, 타 기관·해외 사례 |
| 3 | Ⅱ-2. 대내 환경분석 (7쪽) | 복수노조, 일반직·공무직 구조, 임피 80%·6시간 분석, 인력·직무 현황(미집계 표기) |
| 4 | Ⅲ. 크로스 SWOT (8쪽) | 직무·인사·보수별 SWOT 12요인, SO/WO/ST/WT 조합전략, 6~7대 시사점 |
| 5 | Ⅳ. 전략체계도 (6쪽) | 미션·비전·목표, 3대 전략, 9대 과제, 선후관계, 도식 |
| 6~8 | Ⅴ-전략1·2·3 (각 약 8~9쪽) | 과제마다 현황·쟁점·대안(2~3개 비교)·추진내용·산출물·위험·성과지표 |
| 9 | Ⅵ. 향후 일정 (6쪽) | 2026 월별, 2027~2029 분기별, 시범운영 확인기준, 도입 5대 조건, 위험관리 |
| 10 | 표지·요약·목차 (4쪽) | 한 장 요약, 경영진 판단사항 4개, 확정하지 않는 사항 |

**Ⅴ장 과제 1개당 3쪽 표준 틀**

```
□ (과제명)
○ 왜 필요한가: 문제와 근거 (수치·출처)
○ 현황: 공단 현재 운영 사실 (확인 전/미집계 구분)
○ 대안 비교: 2~3개 안을 같은 기준으로 비교 (표 1개)
○ 추진내용: 2026 → 2027 → 2028 → 2029 단계별
○ 산출물: 무엇이 만들어지는가
○ 위험과 대응: 노사 수용성, 총인건비, 이중감액 등
○ 성과지표: 완료 기준
⇒ 다음 과제로 넘기는 입력값
```

## 5. 5단계 — 검수 (각 장 끝, 그리고 합본 후)

```
방금 쓴 장을 아래 8가지로 검수하고, 문제 목록과 수정안만 표로 알려줘라. 본문은 내가 승인하기 전까지 고치지 마라.
1. 근거 없는 수치·법령·기사가 있는가(출처 없는 숫자 전부 표시)
2. 사실·추정·가정이 섞여 있는가
3. 확정 전 수치를 확정처럼 쓴 곳이 있는가(정년연령, 보수율, 근로시간)
4. 앞 장·표와 숫자가 일치하는가(예: 80%, 6시간, 2029, 9대 과제 번호)
5. 임피 80%·6시간 이중감액 오류가 없는가
6. 같은 말을 반복해 분량만 채운 곳은 어디인가
7. 일반인이 이해하기 어려운 용어에 쉬운 설명이 있는가
8. 공무직·복수노조 관점이 빠진 곳은 어디인가
```

**판단 필요 시 Jev(제브) 활용**: 여러 건을 한꺼번에 "근거 있음/없음", "확정 표현/확인 전 표현"처럼 예·아니오로 판정할 때 사용
- 예: 보고서의 수치 문장 100개를 뽑아 "출처가 붙어 있는가"를 일괄 판정

## 6. 6단계 — 합본과 파일 형식

**중요한 선택: 어떤 파일로 받을 것인가**

| 필요한 형태 | 방법 | 비고 |
|---|---|---|
| 공단 보고서 서식(HTML→PDF) | 퍼블릭 스킬 사용 | 서식 검사기로 규칙 위반 자동 차단. 산출물은 HTML 한 종류 |
| 한글(.hwp/.hwpx)에 붙여 넣는 원고 | 퍼블릭 스킬 HTML 또는 docx를 열어 복사 | 한글 파일 직접 생성은 지원하지 않으므로 docx→한글 열기 권장 |
| MS Word(.docx) | docx 스킬 | 사용자 지시가 우선이므로 요청 시 가능(퍼블릭 스킬 서식 검사는 적용되지 않음) |
| Google Docs | 문서 도구 연결 | 공동 편집·댓글 용도 |

**합본 명령**

```
모든 장을 하나로 합쳐라.
1. 장·표·도식 번호를 처음부터 끝까지 다시 매겨라(표 1~, 그림 1~)
2. 목차와 본문 제목이 일치하는지 대조해라
3. 용어·숫자(80%, 6시간, 2029, 9대 과제)가 전체에서 같은지 검사해라
4. 확인 전 항목, 미집계 항목, 자료요청 목록을 맨 뒤 "붙임: 미확정·미확인 목록"으로 모아라
5. 합본 후 실제 쪽수를 알려주고 70쪽(±3쪽)을 벗어나면 줄이거나 늘릴 절을 제안해라
```
