# Mind 평가논리 검증 질문

1. 기관/연도/평가영역/지표등급과 기관등급은 분리되었는가?
2. 정책 투입과 실제 이행, 산출과 결과, 장기영향을 구분했는가?
3. 목표·기준·실적·단위·기간·모집단·분모가 원문에 있는가?
4. 같은 수치가 다른 페이지에 반복될 때 동일 관측치인지 확인했는가?
5. 성과의 대상범위가 전체인지 남성인지, 사용자 수인지 사용일수인지 보존했는가?
6. '개선으로 인해 증가'를 주장할 비교집단·시간순서·외생요인 통제가 있는가? 없다면 인과 HOLD.
7. 달성률, 증가율, 이용률의 정의를 혼용하지 않았는가?
8. 분모 변경, 신설 제도, 장기 미해결 과제, 커버리지와 잔여대상, flow/stock 착시를 점검했는가?
9. 원문 사실, 후속 연구자의 해석, 재설계 문구의 출처를 분리했는가?
10. 원문 표제·그래프·본문 간 충돌은 이미지/셀 위치 확인 전까지 유보했는가?
11. 우수기관 벤치마크는 해당 세부지표의 긍정 사례 적격성을 검토했는가? 저등급 사례를 우수사례로 승격하지 않았는가?
12. 출고 전 누락필드 및 상태충돌을 검사했는가? 단순 수신 후 동일성 검사만으로 선행 누락을 검출했다고 주장하지 않는가?

결과는 주장별 `SUPPORTED / CONDITIONAL / UNSUPPORTED / CONFLICT`로 기록하고, 전체 단계 판정과 구분한다.
