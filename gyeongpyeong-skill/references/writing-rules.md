# Writing 작성·대조 규칙

## 문장 유형
- 관측: '보고서에는 ○○ 사용자 수가 2024년 A명에서 2025년 B명으로 기재되어 있다.'
- 활동과 병기: '기관은 ○○ 제도개선 활동과 함께 △△ 실적을 제시하였다.'
- 충돌: '○○ 수치는 P102에서 A로 표기되지만 P94/P216에서 제도명이 달라 귀속을 유보한다.'
- 한계(작성자 서술): '제시된 수치만으로 대상자 대비 이용률이나 제도개선의 독립적 인과효과는 확인되지 않는다.'

## 금지패턴 (F1~F7)
- F1 증가율을 이용률이라고 표현
- F2 정책이 실적을 '초래했다', '입증했다'고 근거 없이 단정
- F3 남성/전체 수치 혼합, 사람/일수 혼합
- F4 수치 오기(예: 127→172를 127→173으로)
- F5 같은 지표의 중복 인용(예: P94/P102)을 두 성과로 합산
- F6 원본에 없는 문구를 **원문 인용인 것처럼** 표시. 예: 파생시안의 '[표 전체 성과]', '해석 한계' 주석을 원문에서 따온 것처럼 쓰는 것. (작성자가 자기 서술로 해석 한계를 쓰는 것은 금지가 아니라 필수다.)
- F7 인쇄면 표제 충돌을 텍스트 추출 순서만으로 해결

## 대조표(C) 필드
`claim_id | 문안 문장 | 지표키 | 원문 근거 URL/페이지 | 숫자·단위·연도 | 대상 | 인과표현 | Mind 판정 | 대조 판정 | 수정/유보 사유`

- Mind 판정: SUPPORTED / CONDITIONAL / UNSUPPORTED / CONFLICT
- 대조 판정: MATCH(카드와 일치) / ALTERED(수치·정의·인과가 달라짐) / OMITTED(카드의 필수 한정어·출처가 빠짐) / HOLD(카드 자체가 미확정)

## 검증 루틴
A 사실카드 봉인 → B 문안 작성 → C 주장 단위 대조 → D 금지패턴 점검 → 최종 문안/유보사항 출력.

### D 금지패턴 점검 방법
1. 문안 B의 정량 문장과 인과 표현이 든 문장을 모두 뽑는다.
2. 각 문장을 F1~F7에 하나씩 대어 해당 여부를 적는다.
3. 해당이 1건이라도 있으면 그 문장을 고치고 C의 해당 행을 다시 대조한다.
4. 검증 기록에 `금지패턴 점검: 문장 n개 × 7패턴, 해당 k건, 수정 후 0건` 형태로 남긴다.

수정 후에도 남은 해당 건은 C표에 ALTERED로 적는다(단계 FAIL 사유).

## 독립 반복검증(G4)에 대해
한 대화에서 같은 문장을 세 가지로 바꿔 쓴 것은 블라인드 3회가 아니다. G4는 별도 실행 기록이 있을 때만 인정하며, 없으면 "독립 반복검증 미실행"으로 적는다. G4 미실행은 단계 판정을 낮추지 않는다.
