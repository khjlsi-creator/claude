# 디자이너 규칙 — 2021년 경영실적평가 기관설명회 (참조 B)

‘2021년 경영실적평가 기관설명회’ PPT(2022. 3. 11. 발표, 4:3, 10장)에서 디자이너가 **좌표로 남긴 규칙**을 뽑고, 그 규칙을 지금의 KORAD 16:9 그리드·색·글꼴로 **새로 설계**해 레이아웃 L49~L54(원본 규칙 재설계)와 L55~L61(모듈 변주), 모듈 5종(SectionTitle · TaskCard · ResultCard · PhotoTimeline · OrgChart)으로 추가한 기록입니다.

> 쉽게 말해 “옛 장표를 옆으로 늘린 것”이 아닙니다. 예) 옛 장표에서 표와 성과 칸이 405 : 241로 나뉘어 있었다면, 그 **비율(약 5 : 3)과 이유(윗선을 맞춘다, 아랫선을 맞춘다)**만 가져오고, 칸의 실제 폭은 KORAD 16:9 본문(890.5)에서 새로 계산했습니다. 색·글꼴·모서리는 전부 KORAD 값입니다.

- 이 문서의 원본 도면은 `assets/Reference/`(33장)가 아니라 사용자가 올린 기관설명회 PPTX입니다(슬라이드 720×540pt, 10장). 숫자는 모두 이 원본 도형 좌표를 읽은 값(pt)입니다.
- 원본 33장(`SourceS01`~`S33`)과 L01~L48은 그대로 둡니다. 참조 B는 **원본에 없던 구성이 필요할 때만** 쓰는 추가 레이아웃입니다(`layout-grid.md` 4절).

## 2. 좌표에서 읽은 규칙 (R1~R12)

각 규칙은 “원본에서 잰 값 → KORAD 16:9에서 어떻게 환산했나” 순서입니다. 환산 값은 `designer-grid.md` 6절에 표로 모았습니다.

### R1 바깥 여백은 좌우 대칭
- 원본: 표·박스가 x 29 ~ 692(폭 663), 좌 29 / 우 28pt(슬라이드 폭의 4%).
- KORAD: 이미 `content-left` 34.6 ~ `content-right` 925.1(3.6%)이라 **변경 없음**. 새 모듈도 모두 이 두 선 안에 둡니다.

### R2 소제목 리듬 — “아래는 좁게, 위는 넓게”
- 원본(2번 장): 소제목 높이 19~20, 소제목 아래 → 박스까지 **3~8**, 박스 아래 → 다음 소제목까지 **10~20**(평균 비 약 1 : 2).
- KORAD: 소제목 글자가 16 → 20pt(×1.25)로 커져 높이 26. 아래 8, 위 14(비 1 : 1.75, 본문 높이 383 안에 3개 구역이 들어가도록 약간 눌렀습니다).
- 쉬운 예) 책의 소제목처럼 “제목은 바로 아래 내용에 붙이고, 앞 내용과는 띄운다”는 규칙입니다.

### R3 좌우 모듈 분할은 세 가지 비율뿐
| 원본 장 | 왼쪽 : 사이 : 오른쪽 (pt) | 비율 | KORAD 환산 (pt, 본문 890.2) |
|---|---|---|---|
| 3번 | 205 : 53 : 405 | 1 : 2 + 화살표 | **291.1 : 54 : 545.1** (왼쪽 = 3단 열 폭) |
| 5~9번 | 406 : 10 : 241 | 5 : 3 | **544.4 : 12.5 : 333.3** (사이 = `col2-gap`) |
| 4번 | 480 : 40 : 144 | 3 : 1 + 화살표 | **628.8 : 54 : 207.4** (오른쪽 = 4단 열 폭) |

- 화살표 구간은 왼쪽 모듈 폭의 약 1/4 → KORAD에서는 세 곳 모두 **54**로 통일했습니다.

### R4 두 모듈은 윗선과 아랫선을 맞춘다
- 원본(5~9번): 표 윗선 y 120 = 성과 패널 윗선 y 120, 표·패널 아랫선 = 카드 아랫선 y 286. 4번의 결과 카드도 번호 행 박스와 같은 높이(97 ~ 291).
- KORAD: 모든 좌우 쌍은 윗선·아랫선을 같게 맞춥니다(L49~L54 영역표 참고).

### R5 카드를 여러 개 쌓으면 본문 높이를 똑같이 나눈다
- 원본(5번): 카드 71 ~ 286(215)과 296 ~ 500(204), 사이 10. 합 = 본문 높이.
- KORAD: 카드 2개 = 188.5 × 2 + 6(= 3단 × 2행의 행 높이와 같은 값). 카드 1개면 본문 전체 383.1(L50).

### R6 번호 배지는 제목 띠보다 크고, 띠 앞으로 튀어나온다
- 원본: 육각 배지 50×41 vs 제목 띠 높이 25(배지가 1.6배), 배지가 띠 왼쪽 끝을 덮음.
- KORAD: 배지 56×48 vs 띠 32(1.5배), 배지가 띠 앞 52 ~ 91을 덮음. 배지 안에는 번호만 두고(20pt Bold), 원본에서 배지 안에 있던 분야명(4자)은 띠 안으로 옮겨 `분야명 | 과제명`으로 읽히게 했습니다(구분선은 헤더의 제목 | 소제목 규칙과 같음).

### R7 표는 “선만 있는 머리글 + 옅은 라벨 열”
- 원본: 라벨 열 57 / 표 406 = 14%. 머리글은 선(위쪽 굵은 선)만 있고 칠이 없음. 라벨 셀은 두 톤(추진배경 = 옅은 회색, 추진노력 = 옅은 파랑)으로 구분. 본문 12pt, 불릿 `•` 1단계 / `–` 2단계, 행간 약 130%.
- KORAD: 라벨 열 76, 머리글 윗선만 1.25pt `blue-strong`, 라벨 두 칸은 시스템의 행 라벨과 같은 **trellis 타일**(추진배경 `ko-trellis-blue` → 추진노력 `ko-trellis-teal`, 흰 14pt Bold), 본문 14pt(2단계 12pt), 행간 125%. 이 표는 설명형(문장) 표이고, 숫자 표는 기존 `DataTable` 기본형(머리글 `blue-bright` 채움)을 그대로 씁니다.

### R8 성과 패널은 “머리 14% + 몸체”
- 원본: 패널 머리 23 / 패널 166 = 14%, 2pt 테두리, 몸체 옅은 회색, 제목 글자 사이를 넓게(“추 진 성 과”), 항목은 번호 원(지름 17) + 한 줄.
- KORAD: 한 줄 제목에 맞춰 머리 28(21%), 자간 0.15em. 성과 = 결과이므로 **그린 계열**(1pt `green-400` 테두리, 몸체 `tint-mint-50`, 머리 `ko-trellis-green`), 번호 원 20 `navy-deep`(Governing Message 원과 같은 남색).

### R9 색은 “파랑 4톤 + 의미색 1개 + 회색”
- 원본 사용 색(상위): 하늘 `29ADF1`(선), 패널 머리 `4B9ED1`, 제목 띠 `1F4E79`, 라벨 `B9CDE5`·`A4BDDC`, 의미색 빨강 `DC321C`(소제목 마커·핵심 숫자), 회색 `C0C0C0`(화살표·틀).
- KORAD 환산: 아래 3절.
- 규칙의 핵심: **의미 강조는 색을 늘리지 않고 ‘계열색 + 형광 밑줄’로 합니다.** 원본의 빨강 자리는 그 모듈의 계열색(블루 모듈 `blue-strong`, 결과·성과 모듈 `teal-600`)과 `mint-highlight` 밑줄이 맡습니다(3·6절).

### R10 모듈 사이 흐름은 큰 블록 화살표
- 원본: 폭 약 53, 높이 약 60의 회색 블록 화살표 1개가 “원인 ▶ 결과”를 잇고, 위아래 두 묶음이면 화살표도 두 개(각 묶음 세로 중앙).
- KORAD: 구간 54 안에 40×60, `tint-blue-100` → `blue-cyan` 그라데이션(30번 장표의 `arrow-right` 색과 같은 계열).

### R11 결과는 이중 틀 카드 한 장
- 원본: 두꺼운 회색 틀(6pt) 안에 흰 둥근 카드, 핵심 수치만 크게.
- KORAD: 결과 = 그린 계열이므로 `tint-mint-50` 틀 6 + 흰 카드(`radius-tint`, `shadow-card`). 큰 숫자 40pt Bold `teal-600`(본문 16pt의 2.5배), 결과어 20pt Bold.

### R12 7등분 격자 — 연혁 사진과 조직도 본부가 같은 줄
- 원본(2번): 사진 7칸 x = 28, 125, 222, 317, 415, 511, 608(피치 약 96.7, 폭 83). 조직도 맨 아래 7칸 x = 29, 124, 220, 316, 412, 507, 603(피치 약 95.6, 폭 88). **두 줄이 같은 7등분 격자**를 씁니다.
- KORAD: 폭 112, 피치 129.75(= (890.2 − 112) ÷ 6), 사이 17.75. PhotoTimeline과 OrgChart가 같은 x를 씁니다.

## 5. 색감·톤 철학 — KORAD 전체와 같은 원칙으로 통일

참조 B는 옛 장표의 “파랑 한 가지 + 빨강” 색감을 가져오지 않고, KORAD 시스템이 전체에서 쓰는 철학을 그대로 따릅니다. 쉽게 말해 “신호등처럼 단계가 바뀔 때만 색이 바뀐다”입니다. 예) 과제 카드는 배경(블루) → 노력(틸) → 성과(그린)로 읽히고, 제목 띠만 딥블루입니다.

| 원칙 | 적용 (참조 B) |
|---|---|
| ① **계열 흐름**: 블루 → 틸 → 그린 → 딥블루. 블루 = 현황·근거, 틸 = 과정·노력·상세, 그린 = 결과·성과, 딥블루 = 제목·구조 | TaskCard 라벨 블루 → 틸, 성과 패널·ResultCard 그린, 제목 띠·조직도 최상위 딥블루, L53 요약 블루 ▶ 상세 틸 |
| ② **라벨은 trellis 타일**(흰 Bold 글자 + 작은 그림자) | TaskCard 라벨 칸, 패널 머리, PhotoTimeline 머리 |
| ③ **박스 바탕은 하늘 → 아쿠아 → 민트 틴트** | L51·L56·L58 요약 3칸, L57 설명 박스, 직속 조직 `tint-sky-50` |
| ④ **강조 = 계열색 숫자 + 민트 형광 밑줄**(빨강·주황 글자 금지) | 블루 모듈 `blue-strong`, 결과 모듈 `teal-600` |
| ⑤ **직각이 기본**, 둥근 모서리는 흰 카드·틴트 박스·pill만 | 육각 배지·블록 화살표는 직선 도형, ResultCard만 `radius-card` / `radius-tint` |
| ⑥ **그림자는 두 종류뿐**(`shadow-card`, `shadow-panel-header`) | NumberRows·ResultCard는 `shadow-card` |
| ⑦ **본문 글자는 `navy-ink`**, 보조는 `slate-700`, 캡션 `slate-500` | 모든 표·불릿·설명 |
| ⑧ **표는 DataTable 기본형**: 색 강조 열·줄무늬 금지(합계는 행) | L52·L54·L61 표의 구분 열은 흰색 |
| ⑨ **번호 원은 남색**(`navy-deep`, Governing Message 원과 같은 색) | 성과 항목·번호 행의 원 |
| ⑩ **대비**: 흰 글자는 `blue-panel` 이상(큰 글자·Bold), 그린 계열 흰 글자는 시스템 기존 한계(2.4:1)를 그대로 상속 — 본문은 `navy-ink` | 그린 머리 위 제목 16pt Bold + `shadow-title-text` |

- 새 그라데이션은 두 곳뿐입니다: 블록 화살표(30번 `arrow-right` 계열)와 번호 행 머리 띠(`fade-blue`). 둘 다 기존 토큰 색만 씁니다.
- 새 색 토큰은 만들지 않았습니다(`tokens.json`에는 간격 토큰만 추가).

## 6. 변주 L55~L61 — 모듈을 섞고 바꾸는 규칙

새 모듈로 레이아웃을 더 다양하게 만들 때도 **“원본 모듈은 그대로, 배치·개수·높이만 바꾼다”**는 KORAD 파생 원칙을 지킵니다. 칸은 `designer-grid.md` 6절 값만 씁니다.

| 바꿀 수 있는 것 | 예 | 만든 레이아웃 |
|---|---|---|
| 좌우 맞바꿈 | 표 ↔ 성과 패널(성과 먼저) | L55 |
| 높이 늘이기·줄이기 | 과제 카드 188.5 → 300 / 383.1, 번호 행 박스 163 → 349.1 | L50, L56, L60, L61 |
| 개수(복제) | 번호 행 3 → 4, 포토 칸 7 → 4(4단 열) | L57, L60 |
| 모듈 맞바꿈(같은 칸에 다른 모듈) | 정원 표 → 3단 요약 틴트 | L58 |
| 위아래 조합(열 그리드 2종 이하) | 과제 카드 + 요약 3칸, 요약 ▶ 상세 + 결론 띠 | L56, L59 |
| 소제목·정의 박스 추가 | 표 위 한 줄 요약 | L61 |

바꾸면 안 되는 것: 모듈 안쪽 크기·글자 크기·색·선·계열 순서, 화살표 구간 54, 칸 폭·간격, 좌우 쌍의 윗선·아랫선 일치.

쓰는 법(고르는 순서): ① 내용 구조로 원본(L01~L27) → 트레이스·파생(L28~L48) → 참조 B(L49~L54) → 변주(L55~L61) 순으로 찾습니다. ② 담는 양이 맞는 가장 단순한 것을 고릅니다. 예) 과제 1개 + 수치 3개면 L56, 수치가 하나면 L50.

## 7. 일부러 바꾼 것과 못 한 것 (숨기지 않는 목록)

- **도넛 차트 → 점유율 막대(L53).** 원본 3번의 도넛(파이)은 KORAD 차트 규칙이 금지하므로 KpiBreakdown 행 서식(이름 + % + 막대)으로 바꿨습니다.
- **곡선 화살표·열쇠구멍 일러스트·메달 사진 → 폐지/자리표시.** 사진은 프레임(자리표시)만 만들었습니다. 실제 사진은 프레임 안에서만 바꿉니다.
- **빨강 → 계열색.** 팔레트에 의미색 빨강이 없어 소제목 마커는 `blue-strong`, 핵심 숫자는 모듈 계열색(`blue-strong` / 결과 `teal-600`)으로 바꿨습니다. 경고 뜻이 필요하면 `amber-400` 아이콘만 씁니다(텍스트 금지).
- **둥근 모서리.** 원본 제목 띠 오른쪽 위 모서리의 둥글림은 직각 기본 규칙에 따라 폐지했습니다.
- **소제목 아래·위 간격비.** 원본 1 : 2 → KORAD 1 : 1.75로 압축(R2).
- **샘플 글.** 미리보기의 문장·숫자는 원본 PPT에서 가져온 예시이며, 비중(%) 같은 파생 값은 원본 숫자에서 계산했습니다. 실제 장표에서는 사실 확인 후 교체합니다.
- **원본 5~9번 제목 띠는 비어 있었습니다.** 미리보기 제목은 같은 장의 본문에서 따온 예시 문구입니다.
- **원본 PPTX 대조.** 이 레이아웃들은 원본 좌표의 **관계**를 옮긴 새 설계이므로, 원본과 겹쳐 비교(`quality-gate.md`의 Overlay)하는 대신 이 문서 2절 규칙(윗선·아랫선 일치, 분할 비율, 7등분 격자)이 지켜졌는지로 검수합니다.
