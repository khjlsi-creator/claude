# JSON 사실카드 형식

`scripts/validate_metrics.py`가 읽는 형식이다. 최상위는 **레코드 배열**이다(`{"records": [...]}`로 감싼 형태도 받는다). 예시는 `assets/sample-fact-card.json`.

| 필드 | 입력 계약 항목 | 필수 | 비고 |
|---|---|---|---|
| `institution` | 기관 | 키 | |
| `report_year` | 보고연도 | 키 | |
| `baseline_year` | 기준연도 | 키 | |
| `comparison_year` | 비교연도 | 키 | |
| `program` | 제도 | 키 | 원문 표기 그대로. '육아시간'과 '육아시간제'를 합치지 않는다 |
| `population` | 대상범위 | 키 | 전체/남성 등 |
| `unit` | 단위 | 키 | 명/일 등 |
| `baseline` | 원값 | 값 | `status`가 확보일 때 숫자 |
| `actual` | 신값 | 값 | `status`가 확보일 때 숫자 |
| `change_percent` | 원문 표기 증감률 | 선택 | 있으면 재계산값과 비교(허용오차 ±0.1%p) |
| `status` | 자료상태 | 선택 | `확보`(기본) / `미확보` / `비해당` |
| `source` | 출처 페이지·표/셀 | 권장 | 예: `"P94"` |
| `verified` | 검증상태 | 권장 | `true`/`false` |

키 7개가 정규화 키다. 키 필드가 비었거나 `null`이면 오류다.

## 검사 결과 읽는 법
| 구분 | 의미 | 조치 |
|---|---|---|
| `errors` | 식별키 누락, 숫자 아님, 증감률 불일치, 같은 키에 다른 값 | 고치거나 Mind/원본 확인으로 반환. 종료코드 1 |
| `holds` | `status`=미확보, 또는 확보인데 값이 비어 있음 | 해당 항목 HOLD, 단계 상한 CONDITIONAL |
| `notes` | 같은 키·같은 값의 중복 인용(정상, 1회만 집계), 원값 0(증가율 산출 불가, 신설 제도 가능), 비해당 | 조치 불필요. 문안에서 합산·증가율 표기만 주의 |

`errors`가 없으면 종료코드 0이다. 이 검사는 산술·식별키만 본다. 원문 사실성과 의미는 사람이 확인한다.
