# 용어와 행동 규칙

## 상위 체계 용어 (이 패키지에 정의 원문 없음)
아래 용어의 공식 정의는 이 패키지에 들어 있지 않다. 스킬은 뜻을 추측해 적용하지 않고, 오른쪽 행동 규칙만 따른다.

| 용어 | 이 스킬에서의 행동 규칙 |
|---|---|
| Gold SEALED | 상위 체계의 봉인 상태. 이 스킬은 건드리지 않는다. 해제·갱신을 선언하지 않는다. |
| Original Guard | 상위 체계의 원본 검증 절차(0단계). 이 스킬은 통과를 선언하지 않는다. |
| Renderer Preflight | 상위 체계의 렌더링 사전검사. 이 스킬 범위 밖. |
| Master / 공식 PASS | 상위 체계의 최종 승인. 이 스킬 출력은 항상 "공식 Master PASS 아님". |
| Quality Gate 3 | 상위 체계의 절차. 이 문서의 게이트 **G3과 다르다**. |
| R490, R585, R626, R627, R629 | 선행 연구 체크포인트 번호. `source-index.md`의 링크를 가리키는 이름일 뿐이다. |

## 작업 정의 (패키지 작성자 확인 필요)
아래는 원 패키지에 이름만 있고 설명이 없던 점검 항목이다. 확인 전까지는 이 작업 정의로 점검하되, 결과에 "작업 정의 기준"이라고 적는다.

| 용어 | 작업 정의 |
|---|---|
| 페이지 역할 | 그 페이지가 실적 제시인지, 계획·제도 설명인지, 요약 재인용인지. |
| 서사패턴 | 활동→성과를 잇는 서술 방식. 인과를 암시하는지 병기인지 본다. |
| Proof Anchor | 주장 하나를 받치는 가장 직접적인 원문 위치(페이지·표·셀). 없으면 그 주장은 SUPPORTED가 될 수 없다. |
| tail/coverage | 실적이 대상 전체 중 얼마를 덮는지, 남은 대상(잔여)이 얼마인지. |
| flow/stock | 기간 중 발생량(flow)과 시점 누적량(stock)의 구분. |
| feedback lineage | 지적사항 → 개선활동 → 실적의 연결이 원문에 추적 가능한지. |

## HOLD 사유코드
- `SOURCE_TABLE_HEADER_HOLD`: 표제·셀 위치 미확인
- `LABEL_CONFLICT_HOLD`: 페이지 간 지표명 표기 충돌
- `SOURCE_DUPLICATE_REFERENCE_HOLD`: 같은 관측치의 중복 인용 여부 미확정
- `SOURCE_DERIVATIVE_CONTAMINATION_HOLD`: 원문과 파생시안 혼입 의심
- `MISSING_FIELD_HOLD`: 입력 계약 항목 누락(미확보)
- `CAUSAL_HOLD`: 비교집단·시간순서·외생요인 통제 근거 없음
