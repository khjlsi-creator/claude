# 통합 결과 템플릿

## 입력 및 출처
기관 / 평가연도 / 보고서 / 페이지 / 원본 URL / 검증시점 / 사실카드 버전

## Mind
- 핵심 평가주장 및 평가요건
- 정책활동 → 관측산출 → 관측성과의 연결 (검증된 인과만 표시)
- 지표 정의·정규화 키·분모·중복 출처
- 대안 설명, 외생요인, 미확보 근거, 충돌
- 1단계 판정: PASS / CONDITIONAL / FAIL / 미실행

## Writing
- 평가보고서 문안 (문장별 출처 주석)
- 주장-증거 매트릭스 및 수치 대조
- 보류 문구와 금지 인과 표현 검사
- 2단계 판정: PASS / CONDITIONAL / FAIL / 미실행

## 검증 기록
- 원본 검증 A와 새 작성 B, 대조 C의 별도 기록
- 독립 블라인드 여부, 반복횟수, 홀드아웃 수
- 잔여 리스크 / 다음 실험 / 원문 링크
- 공식 Master PASS 아님, Gold SEALED
